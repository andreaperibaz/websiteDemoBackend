## Tests

There are two options in order to view the backend tests:

1) Run the tests directly:

    mvn test

2) Or view the analysis generated by JaCoCo

    2.1) mvn clean test

    2.2) mvn jacoco:report

    2.3) Open the generated file in a browser:[JaCoCo index.html](../websiteDemoBackend/target/site/jacoco/index.html)
